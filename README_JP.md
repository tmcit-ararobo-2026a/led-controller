# LED コントローラー

NHKロボコン 2026 用 Neopixel WS2813 コントローラーです。  
STM32G4を使用し、DMA経由でRGB LEDの制御を行います。

## LEDテープの種類

本ロボットには3つのLEDテープが搭載されています。

- **前面 LED テープ（115 ピクセル）:** ロボットから見たオブジェクトの場所を表示
- **後方 LED テープ（75 ピクセル）:** ベルト直動のパワーを表示
- **前面上方 LED テープ（28 ピクセル）:** 通信状態および自動操縦ステータスを表示

---

## 前面 LED

ロボットの自己位置推定情報に基づき、対象オブジェクトの位置を示します。  
オブジェクトの角度が `RANGE_MIN` から `RANGE_MAX` の範囲内に収まっている場合にLEDが点灯します。  
ロボットから見たオブジェクトの位置に応じてLEDが点灯・移動します。  
もし、複数のオブジェクトが範囲内に収まった場合、LEDの色が合成されます。  

| オブジェクト / 状態 | LEDカラー | 点灯パターン |
| :--- | :--- | :--- |
| **フラッグ (Flag)** | 水色 (Sky Blue) | 全点灯 |
| **バケツ 1 (Bucket 1)** | 緑 (Green) | 全点灯 |
| **バケツ 2 & 3 (Bucket 2 & 3)** | 赤 (Red) | 全点灯 |
| **移動バケツ (Move Bucket)** | 黄 (Yellow) | 全点灯 |
| **初期状態** | 水色 (Sky Blue) | 全点灯 |
| **範囲外 (Out of Range)** | 赤 & 水色 | ベース全水色 ＋ 両端15個ずつ赤色点灯 |

---

## 後方 LED

ベルト駆動系の現在の出力パワーを表示します。  
点灯するLEDの個数の実装仕様については、以下を参照してください：  
`app/include/app/belt_led_set.hpp`

### ステータス表示

| ベルト状態 | LEDカラー |
| :--- | :--- |
| **発射 OK (Shot OK)** | 緑 (Green) |
| **発射 NG (Shot NOT OK)** | 赤 (Red) |

*※ 出力パワーに応じて、点灯するLEDの個数が動的に変化します。*

---

## 前面上方 LED（通信・自動運転表示）

コントローラーとの通信状態および自動操縦の状態を表示します。

| 通信 / 自動運転ステータス | LEDカラー | 点灯パターン |
| :--- | :--- | :--- |
| **コントローラー通信✕** | 赤 (Red) |  徐々に消灯・点灯 |
| **自動操縦 スタンバイ (Standby)** | 青 (Blue) | 徐々に消灯・点灯  |
| **自動操縦 準備完了 (Ready)** | 青 (Blue) | 全点灯 |
| **自動操縦 追従中 (Tracking)** | 青 (Blue) | 収束・拡散  |
| **自動操縦 移動中 (Moving)** | 緑 (Green) | 収束・拡散  |
| **自動操縦 成功 (Goal)** | 緑 (Green) | 全点灯 |
| **自動操縦 エラー (Fail)** | 赤 (Red) | 全点灯 |
